## 我在做什么・What I do

**01 全案设计 / Interior design**



* 别墅与大平层的平面、立面、材料、软装全案，从量房跟到落地

* 重点在结构与动线，不在堆风格标签

**02 自动化 / Automation**



* Python、PowerShell 脚本：数据抓取、批量处理、日报生成

* 内容流水线：选题 → 脚本 → 封面 → 发布 → 数据回收

* 设计侧的重复劳动：素材批处理、命名归档、CAD / PS 批量操作

**03 市场数据 / Market data**



* A 股板块复盘与个股监控，基于 AKShare、同花顺 iFinD 的自动选股与日报
